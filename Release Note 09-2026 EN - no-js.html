⚡ SDKPIC: DatTDG
⚡ UPDATE REQUIREDBUG FIXED
Fix for ITMS-91065, which made App Store reject IPA builds

App Store Connect rejected IPA builds made with iOS SDK 3.19.1 because a bundled image library was not properly signed. From iOS 3.19.2 the library is fully signed. Android is not affected.

⚡ Before your next IPA submission, you must update to iOS 3.19.2 or Unity 1.19.2 or later, refresh all dependency libraries and rebuild the app.

⚡ UPDATE REQUIREDBUG FIXED
Fix for the Continue button on the Account Protection form for Guest users

SDK now follows the VGA decision on every login exactly, asking for PII only from users who are required to provide it and no longer blocking other Guest accounts by mistake.

⚡ Games with Guest Account Protection enabled must update to Native 3.19.1 or Unity 1.19.1 or later and retest the Guest login flow.

BUG FIXED
No more crashes when opening In-App Message or App Inbox on iOS

iOS games with CleverTap turned off could crash when opening an IAM or App Inbox message with images. IAM and App Inbox now display reliably even with CleverTap off.

⚡ Update soon if your iOS game uses IAM/App Inbox with CleverTap off. Recommended: iOS 3.19.2 / Unity 1.19.2.

CHANGED
Show or hide App Inbox and In-App Message per screen

Studios can hide App Inbox during a match and show it again in the lobby. IAM follows the same state, so Banners and Modals do not pop up while users are focused.

⚡ Games already using App Inbox show/hide should review it before moving to 3.19.0, as the existing call will now apply to IAM too.

For Marketing: IAM campaigns now show at the right moment instead of mid-match, so users are less likely to dismiss them.

🔐 VGAPIC: AnhHTH2
FEATURE
Pick a primary VGA account for users signing in with Apple

When one Apple ID is linked to 2 or more VGA accounts, users choose a primary account on their first web login, and later logins go straight to it. Applies to Club, Shop, My Account, vnggames.com and Player Hub.

⚡ GPP teams using SSO should update their user widget or API to handle VGA selection and switching. No action needed from studios.

CHANGED
SIWA users migrated from the VNG Group store to VNGGames VN

Users keep signing in as normal after the store move, and the share of games ready for web SSO rose from 50% to 80% (39/49 games).

CHANGED
Riot marketing consent completed on all 5 games

VNGGames now has marketing consent on 100% of games as required by PDPL 2025, with users opting in when they declare PII.

🏆 VNGGames ClubPIC: LocLV2
FEATURE
Notification center on Club and Giftcode

A bell icon shows the 5 latest notifications. The system notifies users automatically when they move up or down a tier, get a new or expiring voucher, have unused points, have been away for a while, or when a new game joins Club.

FEATURE
Virtual Shared Unique Code cho Giftcode

One campaign can hand out the same code across multiple games and regions. When a user redeems it, the system swaps in an available real code for that user's game and region. Campaign links in the form /all send users to the right game page automatically.

For Marketing: you can run one code campaign across several games and markets at once, using a single link on every channel.

FEATURE
Loyalty Journey on CFL in-game Membership

Tracks total login days, shows the user's loyalty journey and gives rewards at the 90/180/360-day.

FEATURE
Go Global cho Club

Club now supports multiple languages and time zones, with tiers, rewards and missions configurable per market, ready to expand beyond Vietnam.

🎧 CS PlatformPIC: GiangPMH
FEATURE
Run schedules for each Auto Flow branch

Each branch can have up to 10 run windows, for example only outside office hours or at weekends, so tickets land on the right shift.

⚡ Operations need to re-publish any Auto Flow with schedules for them to take effect.

CHANGED
Auto Flow V2.1 separates statuses by who handled the ticket

Adds 12 [System] and 4 [AI]statuses, so the ticket log shows exactly who changed the status: staff, Auto Flow or AI.

⚡ CS leads/admins should check that handling groups include the new [System] statuses, otherwise queues may look empty.

CHANGED
AI bot understands text, images and video, and remembers 3 hours of chat

The bot can tell what kind of content a customer sent and refers back to the last 3 hours of conversation (up from 1 hour), so replies fit the context better.
